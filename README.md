# Pagination Research

This project built with React + Spring Boot, aims to understand how pagination works, what are the different strategies, their pros and cons, when to use them and when to avoid.

The project is also an exploration on how best we provide the user with an experience of an offset based pagination over a mysql database without the performance degradation that comes with it.

# Tech Stack

- Tanstack
- Javascript
- Vite
- Vitest
- Spring Boot
- Java 21
- Maven
